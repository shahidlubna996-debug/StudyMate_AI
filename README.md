# StudyMate AI

An all-in-one AI-powered study companion built for **FutureTech HackFest 2026**.

StudyMate AI helps students learn, practice, revise, plan their study time, and even think through career decisions — all from one web page, with no login or setup required to build or host it.

## Features

**Core AI tools**
- **Explain This** — plain-language explanations with a real Wikipedia image and a Read Aloud option
- **Quiz Me** — 5 interactive multiple-choice questions on any topic
- **Summarize Notes** — turns messy notes into a clean summary
- **Career Advisor** — describes 3 career paths that fit your interests, with a next step for each

**Supporting tools**
- **Study Planner** — a to-do list that saves your tasks in the browser
- **Brain Break** — a quick memory-matching game
- **Useful Links** — Khan Academy, Wolfram Alpha, Google Scholar, Quizlet
- **NEET & UPSC Prep** — NCERT, NTA NEET, UPSC official site, ClearIAS
- **Quote of the Day** — a fresh motivational quote each day

## Tech Stack

- HTML, CSS, JavaScript (no frameworks)
- [Puter.js](https://developer.puter.com/) — free, keyless AI access (Claude), no backend or API key
- Wikipedia REST API — topic summaries and images
- Web Speech API — built-in browser text-to-speech
- A free public Quotes API
- localStorage — saves Study Planner tasks between visits
