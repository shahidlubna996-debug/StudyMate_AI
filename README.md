# StudyMate AI

An AI-powered study companion built for **FutureTech HackFest 2026**.

StudyMate AI helps students learn faster by using generative AI to explain concepts, generate practice quizzes, and summarize lecture notes — all from a single web page, with no login or setup required to build or host it.

## Features

- **Explain This** — type any concept and get a simple, plain-language explanation with an example
- **Quiz Me** — generates 5 interactive multiple-choice questions on any topic, instantly
- **Summarize Notes** — paste messy notes and get a clean summary with key points pulled out

## Tech Stack

- HTML, CSS, JavaScript (no frameworks)
- [Puter.js](https://developer.puter.com/) — free, keyless access to AI models directly from the browser (no backend server or API key required)
- Claude (via Puter.js) — powers all explanations, quizzes, and summaries

## Focus Areas

Generative AI Applications · Education Technology

## How to Run

1. Download or clone this repository
2. Open `index.html` in any modern browser (or use a local server like VS Code's Live Server)
3. On first use of any feature, you'll be asked to sign in to a free Puter account — this is one-time and lets the AI features run at no cost
